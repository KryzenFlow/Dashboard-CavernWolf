# Bundled music (optional)

Place your personal MP3s here to match the seed catalog in `sidepanel/data/tracks.js`:

```
music/
  bush/glycerine.mp3
  drew/sax_live_01.mp3
```

Only add files you own or have rights to play personally. Frankie's Wall does not stream or upload audio.

After adding files, reload the extension in `chrome://extensions`.
