1. Backend Auto‑Run Enforcement
Make sure your FastAPI startup hook actually respects the new field:
Python@app.on_event("startup")
def startup_event():
    registry = load_registry()
    for name, cfg in registry.items():
        try:
            agent_cfg = AgentConfig(**cfg)
            if agent_cfg.auto_run:
                hot_reload_agent(name, agent_cfg)
                print(f"[AUTO-RUN] Started agent: {name}")
        except Exception as e:
            print(f"[WARN] Could not load agent {name}: {e}")

This ensures agents marked auto_run are live immediately after container start.
