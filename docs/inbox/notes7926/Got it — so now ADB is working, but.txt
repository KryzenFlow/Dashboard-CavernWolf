Got it — so now ADB is working, but your grep returned nothing because older Android 5.1.1 kernels sometimes don’t have model name or CPU architecture fields in /proc/cpuinfo.
That’s why you’re getting a blank result.
We can still detect the CPU ABI (architecture) reliably using Android’s getprop system properties — this works even on older devices.

Try this instead:
Bashadb shell getprop ro.product.cpu.abi
adb shell getprop ro.product.cpu.abilist


ro.product.cpu.abi → Primary ABI (e.g., armeabi-v7a, arm64-v8a, x86).
ro.product.cpu.abilist → All supported ABIs.

Example outputs:
armeabi-v7a
armeabi-v7a,armeabi

or
arm64-v8a
arm64-v8a,armeabi-v7a,armeabi


Why Google Play says “unstable” on Android 5.1.1

Google Play Services has dropped support for Android 5.x (Lollipop).
Many apps (including Baby Shark games) now require Android 6.0+ or even Android 8+.
Even if you install the APK manually, some games won’t run because newer libraries aren’t compatible.
