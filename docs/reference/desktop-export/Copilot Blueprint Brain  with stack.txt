How It Works


Hermes Studio

Your control center for writing, testing, and deploying agent code.
Can push updates to Docker containers instantly.



Reasoning Layer

LlamaIndex agent interprets requests (“Schedule a callback for a real estate lead”).
Decides which “claw” (tool) to use.



Memory Layer

Stores all past interactions, industry-specific templates, and customer data.
Lets your copilot remember preferences across industries.



Claw Layer

Executes the action: sends SMS, runs CLI commands, builds a landing page, etc.
Can be extended with new tools without touching reasoning or memory.




Docker Compose Flow

All three layers run as separate containers but share a network.
Reasoning container talks to Memory DB and Claw container via internal API calls.
You can scale each layer independently (e.g., multiple Claw containers for high-volume SMS).
