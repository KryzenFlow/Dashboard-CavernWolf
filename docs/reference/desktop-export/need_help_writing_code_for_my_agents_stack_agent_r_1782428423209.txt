Memory Design

Short-Term Memory (STM):

Stored in fast-access cache (Redis or in-memory Python dict)
Holds context for the current conversation or task


Long-Term Memory (LTM):

Stored in a vector database (e.g., Weaviate, Pinecone, Chroma)
Indexed by embeddings for semantic recall


Learning Updates:

After each task, STM is distilled into LTM with metadata (timestamp, source, outcome)
Feedback loop updates reasoning patterns




Learning Flow

Stimulus → User asks a question or triggers an event
Reasoning Agent → Uses LLaMA to decide next steps
Memory Agent → Retrieves relevant past experiences
Action Agent (Claw) → Executes the plan
Reflection → Stores results + lessons learned in LTM
Pattern Update → Adjusts reasoning heuristics for future
